# Demo de Rueda Nocturna

Duración prevista: 2 minutos y 50 segundos. Abre el sitio antes de empezar y deja DevTools listo para cambiar el tamaño de pantalla.

| Tiempo | Qué mostrar y explicar |
| --- | --- |
| 0:00–0:20 | “Rueda Libre alquila bicicletas en Medellín. El cliente pidió una campaña para sus recorridos nocturnos y un formulario de inscripción.” |
| 0:20–0:45 | Abrir el sitio principal. Mostrar Rueda Nocturna en el menú y avanzar hasta la cuarta diapositiva del carrusel. Entrar a la campaña. |
| 0:45–1:10 | Recorrer rutas y pasos. Mostrar los tres planes y por qué Pareja se distingue. |
| 1:10–1:50 | Ir a inscripción. Intentar enviar vacío, escribir un celular inválido y luego completar los datos con teclado. Aclarar que la recepción real está pendiente de configurar. |
| 1:50–2:15 | Cambiar a 360 px y emular prefers-color-scheme: dark en Rendering. Mostrar que las cards se apilan y el formulario se lee. |
| 2:15–2:40 | Explicar dos decisiones: Grid cambia las columnas sin anchos fijos; Flex mantiene los botones de los planes alineados aunque tengan textos distintos. |
| 2:40–2:50 | Usar el logo para volver al inicio y mostrar el botón Reserva tu bici. Cerrar el recorrido. |
