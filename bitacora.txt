BITACORA - RUEDA LIBRE

Inicio del proyecto

Use HTML para la estructura, CSS para el diseño y JavaScript para las interacciones
Las paginas principales son inicio, tarifas, reservas y encuentranos
En local use el puerto 5500, GET es la petición para pedir la pagina y 304 indica que se puede usar la copia guardada
Cannot GET significa que no se encontro la ruta solicitada, no que faltara un puerto

Formularios y accesibilidad

Puse lang="es", textos alternativos en las imagenes y titulos en orden
Use label para identificar los campos, required para los obligatorios y radio cuando solo se puede escoger una opcion
El celular tiene que empezar por 3 y tener 10 digitos. El correo usa type="email"
Tambien se reviso la navegación con Tab y el foco visible

Colores y estilos

Deje variables para no repetir los colores y las fuentes en todo el CSS
Los titulos usan Montserrat y los textos Open Sans
Azul Noche y Gris Asfalto funcionan para el texto sobre fondo claro, el naranja lo deje para detalles
Para el conflicto de .activo use #menu a.activo, tiene mas prioridad que #menu a sin agregar !important
box-sizing: border-box incluye el relleno y el borde dentro del ancho

Primera version responsive

Use grid para la portada y las rutas, flex para el encabezado, el pie y los campos cortos
En celular apile el contenido. En las tablas baje el tamaño de letra y el relleno para que no se salieran
Las columnas y los espacios cambian cuando aumenta el ancho

Cambios con Bootstrap

Puse Bootstrap antes de mi CSS para poder conservar los estilos propios
En inicio use container, row y col para la portada, las rutas y la flota
En tarifas separe las tablas y la lista de que llevar. En reservas deje el formulario en 8 columnas y contacto en 4 desde md
En encuentranos use Bootstrap para el menu, el resto sigue con mi CSS
Tambien hice pruebas de cards y beneficios en pruebas/catalogo-bootstrap.html

container centra, row crea la fila y col reparte las 12 columnas
col-12 ocupa toda la fila y col-md-6 ocupa la mitad desde 768 px
En Bootstrap sm empieza en 576, md en 768 y lg en 992 px
Use gap para separar elementos, p para relleno y m para margen

Quite distribuciones propias que chocaban con las columnas de Bootstrap
Tambien puse caption-side: top para que el titulo de las tablas quedara arriba
En esa revision las hojas de CSS pasaron de 974 a 387 lineas, contando comentarios y espacios
Los tiempos que ya tenia anotados eran 1 h 30 min para v1.5 y 1 h 50 min para la version con Bootstrap

Reto 7 - Marca y modo oscuro

En input.css defini los seis colores con @theme y las dos fuentes
Verde Ruta #0284C7, Azul Noche #0F172A, Naranja Pedal #F59E0B
Gris Asfalto #334155, Crema #F8FAFC y Amarillo Farol #FFD166
Conserve los valores anteriores, aunque el nombre Verde Ruta tiene un valor azul
Use dark para seguir el tema del sistema, tambien en cards, campos y bordes

Contraste medido, el minimo para texto normal es 4.5:1

Texto / fondo                 | Resultado
Crema / Azul Noche            | 17.06:1, cumple
Crema / Gris Asfalto          | 9.90:1, cumple
Amarillo Farol / Azul Noche   | 12.38:1, cumple
Amarillo Farol / Gris Asfalto | 7.18:1, cumple
Blanco / Gris Asfalto         | 10.35:1, cumple
Blanco / Azul Noche           | 17.85:1, cumple
Verde Ruta / Azul Noche       | 4.36:1, no cumple

Por eso en oscuro use Crema o Amarillo Farol para el texto, no Verde Ruta

Reto 8 - Limpieza y comparacion

El boton principal repetia sus clases 2 veces y el secundario 4. La card y su etiqueta se repetian 3 veces
Deje solo btn-principal y btn-secundario con @apply dentro de @layer components
Las cards siguen con las clases del kit y ordene las utilidades por layout, espacio, letra, color y estados
Use npm run build, que ejecuta la CLI con --minify

Tamaños medidos sin comprimir, sin imagenes ni fuentes
Tailwind en el reto 8: 13.856 bytes de CSS, en ese momento no necesitaba JS
Bootstrap 5.3.3: CSS 232.803 bytes y bundle JS 80.721, total 313.524 bytes sin el CSS propio
Con el formulario y los planes el CSS final de Tailwind quedo en 14.878 bytes, mas 1.278 del JS propio

Gzip calculado en el reto 8: Tailwind 3.369 bytes, Bootstrap CSS 30.829 y JS 23.858
En Network sin cache se transfirieron 3.647 bytes de Tailwind, 34.001 de Bootstrap CSS y 24.866 de JS
La transferencia incluye cabeceras y puede cambiar entre peticiones
Corregi un 404 en Bootstrap porque a la URL del bundle le faltaba /js/

Criterio       | Bootstrap                         | Tailwind
Aprender       | Empece rapido con las columnas    | Tuve que aprender mas utilidades
Personalizar   | Necesite mi CSS para la marca     | Use los colores desde @theme
Tamaño         | Carga CSS y JS completos          | El CSS de esta landing es mas pequeño
Donde usarlo   | Tablas, formularios y carrusel    | Landing y diseño mas personalizado

Recomiendo Tailwind para la siguiente version por el tema y el tamaño, mantendria Bootstrap donde ya funciona
